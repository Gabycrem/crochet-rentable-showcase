# Crochet Rentable

Aplicación web para ayudar a emprendedoras del crochet a calcular costos,
definir precios, analizar rentabilidad y organizar su negocio.

## Demo

[Ver video de demostración]

## Funcionalidades

- Calculadora de costos y precios
- Gestión de productos
- Simulador de rentabilidad
- Guía interactiva
- Workbook
- Sistema de progreso
- Juegos y aprendizaje
- Autenticación con Supabase

## Stack

React · Vite · Supabase · JavaScript

> El código fuente de este producto es privado.
